# KashafApp

A native Android starter app with local sign up/sign in, clan selection, and four bottom navigation tabs.

## Clans

- Red Clan: RGB red accent
- Green Clan: RGB green accent
- Blue Clan: RGB blue accent

The selected clan and account are stored on-device with `SharedPreferences`. This is a UI prototype; accounts are local to one device and are not connected to a server.

## Build

Open this folder in Android Studio and run the `app` configuration. It uses Java and Android Views with no third-party libraries.
